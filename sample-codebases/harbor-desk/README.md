# Harbor desk

A small JavaScript desk for reserving a harbor slip, quoting a stay, and posting the charge. It is separate from the MoltProtocol app and from the Legacy Billing sample.

Zip this folder and upload it with **New project** on a signed-in account. JavaScript files are parsed. This README and `notes/season.txt` stay in the project and are flagged.

After ingest, run dependency analysis, then generate intent summaries. Send a module to expert review from Intent summaries, confirm or correct it, and then run discrepancy detection.
